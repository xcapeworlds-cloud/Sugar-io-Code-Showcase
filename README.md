# Sugar.io — Unity / C# Code Showcase

A selection of real gameplay scripts from my candy-themed tornado arena prototype, built with Unity and C#.

## Featured systems

**AI Opponents** — `TornadoAI.cs` and `TornadoAINavigation.cs`: opponent decision states, distinct behavior profiles, target selection, obstacle avoidance and stuck recovery.

**Tornado Movement, Growth & Combat** — `Tornado.cs` and `TornadoCombat.cs`: movement and collision handling, sugar-based growth, predator detection, capture and consumption.

**Destructible Environment** — `TornadoDestructible.cs` and `TornadoEnvironmentSuction.cs`: object size requirements, breakable world objects, animated debris suction, and sugar rewards.

## Screenshot
`Unity_Editor_Proof.png` shows the prototype open in the Unity editor, with the candy-colored level, hierarchy, simulator, and destructible object inspector.

## Note
These are **selected source files**, not a complete Unity project. They reference other gameplay components, balance settings, prefabs and shaders that are not included here, so they are not intended to compile or run independently.
